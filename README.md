# Welcome to the phase-0 pages
Phase-0 pages is a "Bếp Nhà" website where recipes are shared, allowing people to learn how to prepare VietNamese dishes.

This phase-0 will consist total 3 pages. It will inclue.

- **Home page: a place where people share recipes for dishes.**
- **Recipe details page: a place to view the details of a dish.**
- **Add recipe page: a place where you want to share your recipes and post them for everyone to see.**

To view the details, please visit this link. -> ( https://99-bn.github.io/recipe-website/ )
